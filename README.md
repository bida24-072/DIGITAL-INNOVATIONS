# Digital Innovations — Company Website

A premium, dark-themed digital agency website for **Digital Innovations**, a Botswana-based studio building websites, apps, and digital products.

![Status](https://img.shields.io/badge/Status-Live-success)
![Made in Botswana](https://img.shields.io/badge/Made%20in-Botswana%20🇧🇼-orange)

---

## ✨ Features

- 🎨 **Premium dark theme** — Charcoal + Electric Orange
- 📱 **Fully responsive** — mobile, tablet, desktop
- ✍️ **Editorial typography** — Instrument Serif + Inter + JetBrains Mono
- 🎬 **Scroll reveal animations** — content fades in as you scroll
- 📊 **Sections included:** Hero · Marquee · Services · Work · Process · Stats · Testimonials · CTA · Footer
- 📧 **Working mailto CTA** — click "Start a Project" opens an email draft
- ⚡ **Zero dependencies** — pure HTML, CSS, JavaScript

## 🚀 Deploy to GitHub Pages

1. Create a repo: `digital-innovations`
2. Upload all 4 files to the root
3. **Settings → Pages → main branch → Save**
4. Live at `https://YOUR-USERNAME.github.io/digital-innovations/`
