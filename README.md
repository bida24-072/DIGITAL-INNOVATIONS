## 🛠️ Customisation

### Change contact details
Search all files for `hello@digitalinnovations.co.bw` and `+267 71 234 567` — replace with real ones.

### Add or edit services
Edit the `services-grid` section in `services.html` and `index.html`.

### Add or edit work
Edit the `work-grid` section in `work.html`. Use `data-category="website"` (or `system`, `app`, `template`, `brand`) so the filters work.

### Change colors
Edit CSS variables at the top of `style.css`:
```css
:root {
    --green: #22C55E;
    --bg: #051310;
    ...
}
